HTML in Nota

The page is the page

Nota does not read this file and lay it out its own way, the way it does a .md or a .tex. It hands the file to WebKit, so what you see is what a browser sees: this page's doctype, its own stylesheet beside it, the colours it asked for, and its pictures.

Live

Type in the column beside this one. The page follows about 150 ms after you stop, from the editor's text rather than from the file, so unsaved edits are the page. It keeps its scroll while it reloads, so an edit near the bottom does not send you back to the top.

Links

This one is an anchor in this page, so it stays here and scrolls. This one leaves, so it opens in your browser: Nota is an editor with a preview beside it, not a browser with an editor beside it.

Scripts

A field is a field, and a button is a button. The script that listens to both is HTML.js beside this file, and it runs here the way it would in a browser. Type, then click.
